      The rule behind it
      
        
      Every object asks.
      One system answers.
      
        
      
          Without a shared decision, every smart object becomes another
          notification. MANNERS gives the whole room one set of manners.
        
      
        
      
          
      Respect
      Read the room first.
      Who is present, what is private, and whether this is a good moment come before urgency.
      
          
      Choose
      Use the gentlest object.
      A quiet glow, a private tap, or speech is chosen to fit the moment.
      
          
      Wait
      Silence is useful.
      If nothing deserves attention—or attention is unavailable—nothing interrupts.
